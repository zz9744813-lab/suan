# 阶段 3.6 落地说明

> 范围: API / Worker 边界清理 — API 不再直接驱动 in-process Worker,
> 全部走 Redis 队列. lifespan 关闭路径加 Redis 连接池 + engine 释放.

## 2. 默认行为变化

| 配置 | 阶段 3.5 默认 | 阶段 3.6 默认 | 备注 |
|------|---------------|---------------|------|
| `worker_run_in_process` | True | **False** | API 不再驱动 in-process Worker |

旧验收流程如果还想走 SQLite 回归, 显式在 `.env` 里写 `WORKER_RUN_IN_PROCESS=true` 即可.

## 3. 关键代码

### 3.1 config.py

```python
worker_run_in_process: bool = False
# 仍允许通过 .env 覆盖到 True (仅用于本地 SQLite 回归, 不要用于生产).
```

### 3.2 routers/study.py (批量上传)

```python
if auto_start_worker and queued_run_ids:
    if not settings.worker_run_in_process:
        async def _enqueue_all_runs() -> None:
            for rid in queued_run_ids:
                await enqueue_dispatch(int(rid))
        asyncio.create_task(_enqueue_all_runs())
    else:
        # 老路径
        asyncio.create_task(_start_worker_after_response())
```

### 3.3 main.py (lifespan)

```python
# shutdown
try: await get_worker().stop()  # 兼容 in-process
except: pass
try: await close_async_pool()  # Redis async pool
except: pass
try: close_sync_redis()         # Redis sync client
except: pass
try: await engine.dispose()     # SQLAlchemy engine
except: pass
```

## 4. 验收清单

阶段 3.6 完成必须满足:

- [ ] `worker_run_in_process=False` 是 config.py 默认值
- [ ] `docker compose up` 起来后, 5 个服务健康, `backend-worker` 持续 arq pickup
- [ ] 拆书上传 (单文件 + 批量) 都不再调 `get_worker().start()` (源码扫描无匹配)
- [ ] 写小说启动 (semi_auto / full_auto) 都不再走 httpx 自调 (源码扫描仅 legacy 分支)
- [ ] lifespan shutdown 不会抛异常, 关闭顺序为 Worker → Redis → Engine
- [ ] `WORKER_RUN_IN_PROCESS=true` 启动后, 老路径仍可用, 业务行为不变
- [ ] 关闭 `backend-worker` 容器后, 拆书 / 写小说接口仍可 200, 任务在 Redis 排队
- [ ] 启动 `backend-worker` 容器后, 之前未完成的任务被 arq 消费
- [ ] `/api/worker/queue-summary` 在 5 个 domain 上都返回非空 result 列表

## 5. 风险与回滚

| 风险 | 缓解 | 回滚 |
|------|------|------|
| 默认 False 后老本地 dev 流程被卡 | .env 显式 `WORKER_RUN_IN_PROCESS=true` 即可 | 同上 |
| 旧 `get_worker()` 在 API 进程被误调 | lifespan shutdown 走 try/except, 不阻塞关闭 | 重启服务 |
| 兜底分支遗留 | 标记为 legacy, 3.7 计划删除 | 阶段 3.7 删除 |
| Redis / Engine 关闭顺序错乱 | 严格 try/except 隔离, 不让一个失败拖死另一个 | 改回老 lifespan |
