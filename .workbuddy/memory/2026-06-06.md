## DeepStudy LLM Rebuild — 7 个核心 Stage 全部接入 LLM

**问题**: DeepStudy 管线 14 个 DAG stage 中只有 2 个有真实 handler（且都是关键词/正则而非 LLM），其余 12 个全是空壳。已定义的 StudyCharacterAgent/StudyEventAgent 等完全没被接入。知识图谱为空，行为模式/写作技巧无产出。

**方案**: 将所有 7 个核心 DeepStudy stage 用 LLM Agent 接入，通过 PromptEngine + LLMRouter 调用真实 LLM。

### 实现
1. **llm_helper.py** — 新建，Stage 上下文的 LLM 调用封装（call_llm + safe_json_loads + truncate_text）
2. **ChapterProfilerStage** — 重写：关键词分类→LLM 章节画像（study_chapter_profile prompt）
3. **EntityExtractorStage** — 重写：正则匹配→LLM 人物识别（study_character prompt）+ 非人物实体提取（study_entity_extract prompt）
4. **EventExtractorStage** — 新建：LLM 事件/伏笔提取（study_event prompt），写入 ForeshadowChain + Entity(event)
5. **SceneBeatExtractorStage** — 新建：LLM 场景节拍提取（study_scene_beat prompt），写入 SceneBeat
6. **RelationshipAnalyzeStage** — 新建：共现人物对→LLM 语义关系抽取（study_relationship prompt），写入 Relationship
7. **BehaviorPatternMineStage** — 新建：LLM 行为模式归纳（study_behavior_pattern prompt），写入 BehaviorPattern + BehaviorPatternEvidence
8. **TechniqueMineStage** — 新建：LLM 写作技巧提炼（study_technique_mine prompt），写入 WritingTechnique

### 新 Prompt (4个)
- `study_chapter_profile`: 章节画像（摘要/叙事功能/视角/基调/冲突/钩子/节奏/密度）
- `study_scene_beat`: 场景节拍（trigger→action→result，14种场景类型）
- `study_entity_extract`: 非人物实体（地点/势力/物品/规则/概念/资源/能力/秘密）
- `study_technique_mine`: 写作技巧提炼（prompt_hint + anti_pattern）

### Coordinator 注册
7 个 handler 全部注册到 `DeepStudyCoordinatorAgent.stage_handlers`，DAG 进度自动推进。
